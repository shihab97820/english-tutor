English Tutor: কম্পিউটার থেকে API key বসাও

key এখানে লিখলে একটা QR কোড আসবে। ফোনের ক্যামেরা দিয়ে স্ক্যান করলে অ্যাপ খুলবে আর key নিজে থেকে সেভ হয়ে যাবে। key কোনো সার্ভারে যায় না, শুধু এই পেজ থেকে QR কোডে, তারপর তোমার ফোনে।

  1. ফোনের ক্যামেরা (বা Google Lens) দিয়ে নিচের QR কোড স্ক্যান করো।
  2. যে লিংক দেখাবে সেটা Chrome-এ খোলো। অ্যাপ "API key সেভ হয়েছে ✅" দেখাবে।
  3. APK install করা থাকলেও এটা চলবে, কারণ APK আর Chrome একই ডেটা ব্যবহার করে।

কাজ শেষ হলে "মুছে ফেলো" চাপো। লিংকে তোমার key আছে, তাই এটা অন্য কাউকে পাঠিও না।
